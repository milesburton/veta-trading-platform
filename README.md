## Quick start

```sh
# 1. Clone and open in a Dev Container (VS Code or JetBrains).
git clone git@github.com:milesburton/veta-trading-platform.git
cd veta-trading-platform

# 2. Inside the container, start the stack.
docker compose up -d

# 3. Run the frontend dev server.
cd frontend && npm run dev

# 4. Sign in at http://localhost:5173/ as any persona, passcode: veta-dev-passcode
```

Full instructions are in the [Quick start](https://milesburton.github.io/veta-trading-platform/guides/quick-start/) page.
