## Where to run what

| Environment | Trading stack | LGTM stack | k6 |
|-------------|---------------|-----------|----|
| `local` (devcontainer) | yes | optional | optional |
| `homelab prod` (`veta.mnetcs.com`) | yes | yes | manual |

LGTM and k6 are deliberately optional locally — they add real overhead and the platform runs fine without them. Bring them up when you are investigating performance, debugging event flow, or generating data for the performance docs.
