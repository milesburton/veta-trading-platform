VETA is a simulation, but the discipline around running it is not. This section is the **plan of record** for how the platform is operated, what we measure, and how we recover when things break. New work should reference these pages before changing anything in the deploy or monitoring path.

<Aside type="note" title="Why this document exists">
On 2026-05-12 the platform suffered multiple back-to-back partial outages caused by deploy-mechanism failure (Watchtower stopping containers it then couldn't recreate). The outages were invisible to monitoring and only surfaced when a human noticed the UI was broken. That is not the operational posture of a system anyone would be willing to trade real money against. This document defines the posture we **will** operate to instead.
</Aside>
