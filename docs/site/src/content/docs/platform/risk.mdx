## Pre-trade risk engine (port 5032)

The <Svc name="oms" /> calls `POST /check` on the <Svc name="risk-engine" /> synchronously before routing every order. If any check fails, the order is **rejected** with a specific reason code. If the <Svc name="risk-engine" /> is unreachable (3s timeout), the order is rejected. Real firms halt trading rather than bypass pre-trade risk.

### Checks

| # | Check | Code | Default | What it prevents |
| --- | --- | --- | --- | --- |
| 1 | Fat-finger price collar | `FAT_FINGER_PRICE` | 5% from mid | Typo prices |
| 2 | Duplicate order detection | `DUPLICATE_ORDER` | 500ms window | Double-clicks |
| 3 | Max open orders per user | `MAX_OPEN_ORDERS` | 50 orders | Runaway algos |
| 4 | Self-cross prevention | `SELF_CROSS` | (none) | Own BUY crossing own SELL |
| 5 | Order size vs ADV | `ORDER_SIZE_VS_ADV` | 10% of ADV | Market impact |
| 6 | Rate limiting | `RATE_LIMIT` | 10 orders/sec | Algo floods |
| 7 | Market hours | `MARKET_CLOSED` | Enforced | Orders outside the trading session |
| 8 | Gross notional limit | `POSITION_NOTIONAL_LIMIT` | $5,000,000 post-trade | Oversized books |
| 9 | Daily loss stop | `DAILY_LOSS_STOP` | -$50,000 | Runaway losses |
| 10 | Concentration limit | `CONCENTRATION_LIMIT` | 25% of gross | Single-name concentration |
| 11 | Max position size | `MAX_POSITION_SIZE` | $5,000,000 per symbol | Oversized single positions |

### Configuration

All thresholds are runtime-editable via `PUT /config` with no restart:

```json
{
  "fatFingerPct": 5.0,
  "maxOpenOrders": 50,
  "duplicateWindowMs": 500,
  "maxOrdersPerSecond": 10,
  "maxAdvPct": 10.0,
  "maxGrossNotional": 5000000,
  "maxDailyLoss": -50000,
  "maxConcentrationPct": 25,
  "haltMovePercent": 10,
  "breakerCooldownMs": 60000,
  "breakersEnabled": true,
  "selfCrossEnabled": true,
  "marketHoursEnforced": true
}
```

## Live positions

The <Svc name="risk-engine" /> tracks positions from `orders.filled` bus events in real-time.

- `GET /positions/:userId`: per-symbol net qty, avg price, mark price, unrealised/realised/total P&L
- `GET /positions`: all users' positions

### P&L calculation

- **Unrealised**: `netQty * (markPrice - avgPrice)`, updated on every price refresh (5s)
- **Realised**: accumulated when fills reduce or flip a position
- **Total**: unrealised + realised
