A small inline dot used throughout the app to indicate the health of a service, connection, or job: green for OK, red for error, grey for unknown.

  </span>
</div>

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `state` | `"ok" \| "error" \| "unknown"` | (none) | Required. Drives the dot colour and glow. |
| `className` | `string` | `""` | Extra Tailwind classes, e.g. spacing or larger size. |

## Import

```tsx
import { StatusDot } from "../components/StatusDot";

<StatusDot state="ok" />
```
