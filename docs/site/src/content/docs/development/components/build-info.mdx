Tiny component used in headers and footers to surface the build's commit SHA and date. Shows nothing if neither is provided — drop-in safe.

## Live demo

  <div><BuildInfo client:load commitSha="824da2b94f1e5d6c7a3b" /></div>
  <div><BuildInfo client:load buildDate="2026-05-04" /></div>
  <div style={{ color: "#64748b" }}>↑ third row above is also valid: with no props it renders nothing.</div>
</div>

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `buildDate` | `string?` | — | ISO date or any human-readable date. Optional. |
| `commitSha` | `string?` | — | Full or short SHA — only the first 7 chars are shown. Optional. |
| `className` | `string?` | `text-[10px] text-muted tabular-nums` | Override styling entirely. |

## Import

```tsx
import { BuildInfo } from "../components/BuildInfo";

<BuildInfo buildDate="2026-05-04" commitSha={import.meta.env.VITE_COMMIT_SHA} />
```
