A controlled search-as-you-type dropdown for picking an asset from a list, with the current market price displayed inline. Used inside the order ticket and a few panels.

## Live demo

Try typing `AA`, `JPM`, or `EUR`. Clicking a row in the dropdown calls `onSelect`.

## Props

| Prop | Type | Description |
| --- | --- | --- |
| `assets` | `AssetDef[]` | The full pool to search over. Filtered case-insensitively against `symbol`. |
| `value` | `string` | The current text in the search box (controlled). |
| `onChange` | `(v: string) => void` | Called as the user types. |
| `onSelect` | `(symbol: string) => void` | Called when the user clicks a row in the dropdown. |
| `prices` | `MarketPrices` | Map of `{ [symbol]: price }`. The price for the selected or typed symbol is shown inline. |
| `inputRef` | `RefObject<HTMLInputElement>?` | Optional ref for focus management. |

## Import

```tsx
import { AssetSelector } from "../components/AssetSelector";

const [value, setValue] = useState("");

<AssetSelector
  assets={allAssets}
  value={value}
  onChange={setValue}
  onSelect={(sym) => placeOrder(sym)}
  prices={livePrices}
/>
```
