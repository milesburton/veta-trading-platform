Renders one row of the Service Health table — a status dot, the service name (optionally a link), an `ok / error / unavailable` label, the version, and a meta blurb. Optional services that are erroring are shown in a faded "unavailable" style instead of red.

## Props

| Prop | Type | Description |
| --- | --- | --- |
| `svc` | `ServiceHealth` | Required. See type definition below. |

`ServiceHealth` shape:

```ts
interface ServiceHealth {
  name: string;
  state: "ok" | "error" | "unknown";
  version: string;
  meta: Record<string, string | number>;
  lastChecked?: number;  // unix ms
  link?: string;
  optional?: boolean;     // if true, error → "unavailable" instead of red
}
```

## Import

```tsx
import { ServiceRow } from "../components/ServiceRow";

<table>
  <tbody>
    {services.map((svc) => <ServiceRow key={svc.name} svc={svc} />)}
  </tbody>
</table>
```
